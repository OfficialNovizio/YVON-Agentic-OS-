# Governance Disclosure

## Introduction

Governance disclosure for prism — SOX + DGCL + Fink annual letters + ISS/
Glass Lewis + IFRS S1 governance + GRI 200 series.

Custom Route D per §8.2. §4.6 reclass.

## Description

Governance disclosure — board composition + executive compensation + risk
governance + ethics + anti-corruption + political engagement. LOAD-BEARING
governance-disclosure-without-counsel-review refusal.

## Triggers

governance disclosure / board composition report / executive compensation
disclosure / proxy statement / SOX 302/404 / ISS Glass Lewis alignment /
ethics + anti-corruption reporting / political engagement disclosure

## Purpose

Prevents six failure modes:

1. **Governance disclosure without counsel review.** SOX + DGCL + securities
   laws = strict-liability regime. LOAD-BEARING per Principle 1.
2. **Board composition metric gaming.** DEI + independence + tenure metrics
   scrutinized by ISS/Glass Lewis + investors.
3. **Executive-comp disclosure incomplete** per SEC Item 402 + Say-on-Pay.
4. **Political-engagement disclosure absent** — increasingly expected.
5. **Anti-corruption program cosmetic** without cited controls.
6. **Individual crisis DURING disclosure crunch.** HARD BOUNDARY.

## Structure

```
GOVERNANCE DISCLOSURE COMPONENTS

  BOARD COMPOSITION
    - Independence (per NYSE / NASDAQ standards)
    - Diversity (per ISS/Glass Lewis benchmarks)
    - Tenure + refreshment
    - Committee structure + charters (coordinate pilot risk-committee)

  EXECUTIVE COMPENSATION
    - SEC Item 402 (CD&A + tables)
    - Say-on-Pay (Dodd-Frank)
    - Pay-vs-performance (SEC 2022 rule)
    - Clawback policies (SEC 2023 rule)

  RISK GOVERNANCE
    - Board risk oversight (coordinate pilot)
    - CRO role + reporting line
    - Enterprise risk framework

  ETHICS + ANTI-CORRUPTION
    - Code of conduct + training completion (coordinate grove)
    - Whistleblower channels
    - FCPA / UK Bribery Act / anti-corruption program
    - Investigations + outcomes (aggregate)

  POLITICAL ENGAGEMENT
    - Political contributions (US)
    - Lobbying expenditure
    - Trade association memberships


PROXY ADVISORY ALIGNMENT (ISS / Glass Lewis)

  Voting policies + governance benchmarks matter for shareholder support.


OPERATIONAL SEQUENCE:

  Phase 1: DISCLOSURE-REQUIREMENT MAPPING PER JURISDICTION
  Phase 2: LOAD-BEARING COUNSEL-REVIEW BEFORE PUBLICATION
  Phase 3: ISS/GLASS LEWIS ALIGNMENT CHECK
  Phase 4: STAKEHOLDER ENGAGEMENT + FEEDBACK LOOP
```

## Instructions

Phase 1 — jurisdiction mapping (SEC / DGCL / EU CSRD / international).
Phase 2 — counsel review — LOAD-BEARING per Principle 1.
Phase 3 — ISS/Glass Lewis alignment.
Phase 4 — investor engagement.

## Output

- Disclosure requirement map per jurisdiction
- Governance disclosure artifacts (board / comp / risk / ethics / political)
- Counsel-review sign-off tracker
- ISS/Glass Lewis alignment check
- Investor engagement summary

## Principles

1. **Never governance disclosure publication without counsel review** —
   LOAD-BEARING per Purpose failure mode 1.
2. **Board composition data cited** from board records.
3. **Executive comp per SEC Item 402** complete.
4. **Political engagement disclosed** per increasingly-common expectation.
5. **Anti-corruption program with cited controls.**
6. **No fabrication** — Universal Principle 1.
7. **Aggregate-only at publication surface** — Universal Principle 2. Individual
   director / executive compensation data per SEC-required disclosure only.
8. **Individual crisis HARD BOUNDARY** — Universal Principle 3 inherited.
9. **§0.6 flag.** Sources Tier B.

## Fallback

- Counsel-review delayed → HOLD publication.
- ISS/Glass Lewis misalignment → coordinate operator + board + counsel for
  policy response.
- Investigation-disclosure timing question → coordinate counsel + beacon
  crisis-comms.
- Individual crisis signal → HARD BOUNDARY per Universal Principle 3.
