# Social Impact Metrics

## Introduction

Social impact metrics for prism — GRI Social Standards + B Lab + Impact
Management Project + practitioner.

Custom Route D per §8.2. §4.6 reclass.

## Sources

- GRI Social Standards (400 series) — labor + human rights + community + supplier
- B Lab — B Corp Assessment methodology

- ILO Conventions (§8.9 with canopy employment-law)

## Description

Social impact metrics per GRI + B Lab + IMP frameworks. Employee (DEI /
compensation / safety) + supplier + community + human rights. LOAD-BEARING
aggregate-only + individual-employee-data-protection (Universal Principle 2
execution).

## Triggers

social impact metrics / DEI reporting / employee safety metrics / supplier
audit / community impact / human rights disclosure / B Corp assessment /
IMP impact measurement

## Purpose

Prevents six failure modes:

1. **Individual employee data in social reporting.** Aggregate-only per
   Universal Principle 2. LOAD-BEARING at execution surface.
2. **DEI metric fabrication or gaming.** DEI = HR-sensitive + investor-
   scrutinized. Cited data only.
3. **Supplier audit without follow-through** — audit findings without
   corrective action = performative.
4. **Human-rights disclosure without stakeholder engagement.**
5. **B Corp / IMP framework confusion.**
6. **Individual crisis DURING social-metrics crunch.** HARD BOUNDARY.

## Instructions

Phase 1 — GRI 400 selection per business + SASB industry.
Phase 2 — aggregate-only measurement; individual data stays in HR systems.
Phase 3 — stakeholder engagement (employees + suppliers + community).
Phase 4 — supplier audit + corrective action.
Phase 5 — publication + third-party assurance.

## Output

- Social metric framework
- Aggregate metrics per GRI category
- Stakeholder engagement summary
- Supplier audit + corrective action tracker
- Publication + assurance handoff

## Principles

1. **Individual employee data NEVER in social reporting** — LOAD-BEARING
   per Purpose failure mode 1. Universal Principle 2 execution enforcement.
2. **DEI metric cited from HR data** — coordinate with hire (P&C Lead) +
   HR + counsel.
3. **Supplier audit follow-through** mandatory.
4. **Stakeholder engagement** for human rights.
5. **ILO alignment** for labor rights.
6. **No fabrication** — Universal Principle 1.
7. **Aggregate-only** — Universal Principle 2 (LOAD-BEARING execution).
8. **Individual crisis HARD BOUNDARY** — Universal Principle 3 inherited.
9. **§0.6 flag.** Sources Tier B.

## Fallback

- Small-cohort suppression per Universal Principle 4 minimum-group-size.
- HR data-access issue → coordinate hire + HR + counsel.
- Supplier audit finding severe → escalate operator + counsel.
- Individual crisis signal → HARD BOUNDARY per Universal Principle 3.
