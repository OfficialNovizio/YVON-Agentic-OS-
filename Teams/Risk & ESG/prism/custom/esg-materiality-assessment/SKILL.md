# ESG Materiality Assessment

## Introduction

ESG materiality assessment for prism — SASB + IFRS S1/S2 + GRI + Eccles
+ TCFD.

Custom Route D per §8.2. §4.6 reclass.

## Sources

- SASB (Sustainability Accounting Standards Board — now part of IFRS Foundation)
- IFRS S1 + S2 (2023) — General Sustainability + Climate Disclosure
- GRI (Global Reporting Initiative) — Universal Standards
- Eccles, Robert G. — Sustainability practitioner-academic corpus
- TCFD (Task Force on Climate-related Financial Disclosures)

## Description

Double-materiality assessment — financial materiality (SASB / IFRS) +
impact materiality (GRI double-materiality). LOAD-BEARING no-materiality-
without-double-materiality-assessment. Triggers: "ESG materiality for [org]",
"double materiality assessment", "SASB materiality for [industry]", "IFRS
S1 S2 materiality".

## Purpose

Prevents six failure modes:

1. **Materiality without double-materiality assessment.** IFRS S1/S2 +
   SASB emphasize financial materiality; GRI + EU CSRD require ALSO
   impact-materiality (org's impact on world). LOAD-BEARING per Principle 1.
2. **Industry-agnostic materiality.** SASB standards are industry-specific;
   generic materiality misses relevant topics.
3. **Stakeholder engagement absent** — materiality requires stakeholder input.
4. **Materiality static.** Environment changes; annual refresh needed.
5. **Materiality without governance approval** — board-level topic.
6. **Individual crisis DURING materiality crunch.** HARD BOUNDARY.

## Structure

```
DOUBLE-MATERIALITY (EU CSRD + GRI)

  FINANCIAL MATERIALITY (SASB + IFRS S1/S2)
    - Effect on enterprise value / financial performance
    - Investor-focused

  IMPACT MATERIALITY (GRI)
    - Org's impact on people + planet
    - Broader stakeholder-focused

  BOTH required for comprehensive ESG reporting.


OPERATIONAL SEQUENCE:

  Phase 1: STAKEHOLDER ENGAGEMENT MAPPING
  Phase 2: SASB INDUSTRY STANDARD APPLICATION
  Phase 3: LOAD-BEARING DOUBLE-MATERIALITY ASSESSMENT
  Phase 4: GOVERNANCE APPROVAL + ANNUAL REFRESH
```

## Instructions

Phase 1 — stakeholder mapping (investors + customers + employees + community +
regulators).
Phase 2 — SASB industry-standard applied.
Phase 3 — double-materiality (financial + impact) — LOAD-BEARING.
Phase 4 — board approval + annual refresh.

## Output

- Materiality assessment memo (double-materiality)
- SASB industry-standard application
- Stakeholder-engagement summary
- Board approval brief + annual refresh schedule

## Principles

1. **Double-materiality mandatory** — LOAD-BEARING per Purpose failure mode 1.
2. **SASB industry-specific** application.
3. **Stakeholder engagement** mandatory input.
4. **Annual refresh minimum.**
5. **Board approval** governance.
6. **No fabrication** — Universal Principle 1.
7. **Aggregate-only** — Universal Principle 2.
8. **Individual crisis HARD BOUNDARY** — Universal Principle 3 inherited.
9. **§0.6 flag.** Sources Tier B.

## Fallback

- Stakeholder access constrained → coordinate operator + counsel for
  engagement plan.
- Board approval delayed → provisional materiality flagged.
- Individual crisis signal → HARD BOUNDARY per Universal Principle 3.

- International jurisdiction → canopy
