# Agent-Reach — install guide

Gives agents access to Twitter/X, Reddit, YouTube, GitHub, Bilibili, XiaoHongShu and more with zero API fees.

## Install

```bash
pip install https://github.com/Panniantong/agent-reach/archive/main.zip
agent-reach install --env=auto
```

## Verify

```bash
agent-reach doctor
```

Shows which platforms are configured and working.
