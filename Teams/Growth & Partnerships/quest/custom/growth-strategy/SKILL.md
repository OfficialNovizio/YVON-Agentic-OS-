# Growth Strategy

## Introduction

Growth strategy framework for quest — Roberge revenue-machine + Chen network-
effects + Ellis/Brown growth-hacking + Bush PLG. Stage-appropriate growth
strategy (early / growth / scale).

**Scope distinction:** quest OWNS growth strategy. closer / lure / bond
siblings execute sales / marketing / partnership tactics. Actual execution =
operator + relevant execution team.

Custom Route D per §8.2.

## Purpose

Prevents seven failure modes:

1. **Stage-inappropriate growth strategy.** Early-stage (pre-PMF) tactics
   applied at scale-stage = wasted spend. Scale-stage tactics applied pre-
   PMF = premature scaling.
2. **Fabricated growth projections.** Round-number growth targets without
   evidence = fantasy planning. LOAD-BEARING per Principle 1.
3. **Growth-hacking substituting for GTM strategy.** Tactics without underlying
   revenue-machine strategy = short-term wins + long-term drift (Roberge
   discipline).
4. **Network-effect assumption without evidence.** Claiming network effects
   without cited data on user-to-user value transfer = strategic-plan
   fabrication.
5. **PLG-vs-Sales-Led false dichotomy.** Most modern SaaS = hybrid; forcing
   pure PLG or pure Sales-Led = suboptimal.
6. **Growth-team-only framing.** Growth requires product + marketing + sales
   + CS coordination. Growth-team-siloed strategy = execution gaps.
7. **Individual crisis DURING growth-planning crunch.** HARD BOUNDARY.

## Structure / Protocol

```
GROWTH STAGES (Roberge + practitioner framing)

  EARLY (pre-PMF to $1M ARR)
    - Focus: product-market fit + first-repeatable-motion
    - Tactics: founder-led sales, direct customer discovery
    - Anti-pattern: premature scaling / paid-acquisition dependence

  GROWTH ($1M to $10-50M ARR)
    - Focus: repeatable sales motion + demand-gen engine
    - Tactics: sales team hiring, marketing-attribution instrumentation,
      first-partnership programs
    - Roberge canonical framework applies most directly here

  SCALE ($10-50M+ ARR)
    - Focus: multi-motion optimization + segment expansion +
      international
    - Tactics: multi-product / multi-segment / multi-geography;
      partnerships as revenue channel
    - Coordination with Global Expansion (compass / canopy / lingua /
      frontier) becomes material


REVENUE MACHINE FRAMEWORK (Roberge 2015)

  Roberge's revenue-machine components:
    1. HIRING FORMULA — repeatable sales-hiring per role profile
    2. TRAINING FORMULA — repeatable ramp-time + productivity
    3. MANAGEMENT FORMULA — repeatable coaching + metrics
    4. DEMAND-GENERATION FORMULA — repeatable inbound-lead engine

  Machine assessment: which formulas are formalized? which are ad-hoc?


NETWORK EFFECTS (Chen 2021)

  Direct: user value increases with more users (social platforms)
  Two-sided: value transfers between user groups (marketplaces)
  Data: model improves with usage (AI products)
  Cold-start problem: early network below critical mass — solve via
    manual matching, hard-side subsidies, atomic-network launch


GROWTH-HACKING METHODOLOGY (Ellis/Brown 2017)

  1. Team + tools setup (cross-functional growth team)
  2. Rapid experimentation cadence
  3. ICE / RICE prioritization (Impact × Confidence × Ease)
  4. North-star metric + input metrics
  5. Learning-loop discipline


PLG vs SALES-LED vs HYBRID (Bush 2019 + practitioner)

  PLG dominant: product-driven acquisition + activation + expansion
  Sales-Led dominant: sales-driven acquisition + product delivers value
  Hybrid: PLG acquisition + Sales-Led expansion (common modern SaaS)


GROWTH-STRATEGY OPERATIONAL SEQUENCE:

  Phase 1: STAGE ASSESSMENT                              (early / growth / scale)
  Phase 2: REVENUE-MACHINE COMPONENT AUDIT                (Roberge formulas)
  Phase 3: NETWORK-EFFECT ASSESSMENT (if applicable)      (Chen — evidence-cited)
  Phase 4: GROWTH-MODEL SELECTION                         (PLG / Sales-Led / Hybrid)
  Phase 5: GROWTH-EXPERIMENT ROADMAP                       (Ellis/Brown — ICE/RICE-scored)
```

## Instructions

### Phase 1 — Stage assessment
- Confirm ARR + trajectory
- Confirm PMF signal (retention + organic-growth + sales-cycle metrics)
- Confirm scale-stage transition readiness

### Phase 2 — Revenue-machine component audit
Assess Roberge 4-formulas:
- Hiring formula (repeatable role profile? scoring? ramp?)
- Training formula (documented? outcome-measured?)
- Management formula (coaching cadence? metrics dashboard?)
- Demand-generation formula (inbound engine? lead-quality signals?)

Gaps → prioritized formalization plan.

### Phase 3 — Network-effect assessment (if applicable)
For products with network potential:
- Type identification (direct / two-sided / data)
- Current network density evidence (cited data)
- Cold-start solve if pre-critical-mass
- **Never claim network effect without cited evidence** (Principle 4)

### Phase 4 — Growth-model selection
- Product characteristics (self-serve viable? high-touch required?)
- Customer buying patterns (PLG-compatible? Sales-Led-required?)
- Recommend PLG / Sales-Led / Hybrid with rationale
- Coordinate with quest `gtm-motion-selection` sibling for detailed
  motion-design

### Phase 5 — Growth-experiment roadmap
- Cross-functional growth team (product + marketing + sales + CS coordination)
- Experiment cadence
- ICE / RICE prioritization
- North-star metric + input metrics
- Learning-loop discipline

## Output Format

- Stage-assessment memo (early / growth / scale + PMF signal)
- Revenue-machine audit (Roberge 4-formulas + gap plan)
- Network-effect assessment (if applicable — evidence-cited)
- Growth-model recommendation (PLG / Sales-Led / Hybrid + rationale)
- Growth-experiment roadmap (ICE/RICE-scored)

## Principles

1. **Never fabricated growth projections** — LOAD-BEARING per Purpose failure
   mode 2. Round-number targets without evidence = fantasy planning.
2. **Stage-appropriate strategy** — early / growth / scale sizing matters.
3. **Revenue-machine framework mandatory** — no growth-hacking as strategy
   substitute (Roberge discipline).
4. **Network-effect claims require cited evidence** — no unsubstantiated
   network-effect claims.
5. **PLG-vs-Sales-Led false dichotomy avoided** — most modern SaaS = hybrid.
6. **Cross-functional coordination** — product + marketing + sales + CS
   coordinated.
7. **No fabrication** — cited institutional + practitioner sources. Universal
   Principle 1.
8. **Aggregate-only at publication surface** — Universal Principle 2. Individual
   customer / employee / competitor data stays in internal tools.
9. **Individual crisis HARD BOUNDARY** — Universal Principle 3 inherited.
10. **§0.6 flag.** Sources Tier B.

## Fallback

- **PMF signal ambiguous** — coordinate with Product + operator for PMF
  measurement before growth-stage recommendation.
- **Round-number growth-target pressure** from operator / board. Decline per
  Principle 1 — LOAD-BEARING. Provide evidence-cited alternatives + confidence
  intervals.
- **Network-effect claim without evidence** — decline per Principle 4.
  Coordinate with dana + Product for network-density measurement.
- **Multi-product / multi-segment complexity** — coordinate with operator +
  marcus / vista for portfolio-level strategy.
- **International growth dimension** — coordinate with compass (Global
  Expansion Lead) for market-selection input.
- **Individual crisis signal.** STOP. Route per Universal Principle 3.
