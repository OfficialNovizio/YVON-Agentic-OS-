# Channel Partner Program

## Introduction

Channel partner program discipline for bond — Rangan + Impartner/Allbound PRM
+ Forrester + Salesforce PRM + Winning by Design.

Custom Route D per §8.2.

## Purpose

Prevents six failure modes:

1. **Revenue-share agreement without counsel.** Revenue-share structures have
   tax + accounting + contract implications. LOAD-BEARING per Principle 1
   (Universal Principle 5 inherited).
2. **Program-without-enablement.** Partners signed without training + tools =
   underperformance + churn.
3. **Deal-registration conflict.** Partners + internal sales competing for
   same deals without clear rules = channel conflict.
4. **PRM sprawl.** Multiple disconnected partner-tools = data silos + partner
   experience friction.
5. **MDF (Market Development Funds) without accountability** — money spent
   without ROI tracking.
6. **Individual crisis DURING channel-crunch.** HARD BOUNDARY.

## Structure / Protocol

```
PROGRAM COMPONENTS (Rangan + Forrester)

  - Tier structure (from partner-selection-and-tiering sibling)
  - Benefits per tier (discount / MDF / lead-referral / co-marketing)
  - Enablement: training + certification + tools
  - Deal registration + protection rules
  - Revenue-share / commission structure
  - PRM tool (portal + tracking + reporting)
  - MDF (Market Development Funds) with ROI tracking
  - Partner satisfaction measurement


DEAL REGISTRATION DISCIPLINE

  - Partner registers deal → gets exclusive protection for period
  - Registration expires if no progress
  - Conflict resolution: first-registered typically wins
  - Coordinate with closer for internal-sales alignment


OPERATIONAL SEQUENCE:

  Phase 1: PROGRAM DESIGN                                (structure + tier benefits)
  Phase 2: ENABLEMENT DESIGN                             (training + certification + tools)
  Phase 3: LOAD-BEARING REVENUE-SHARE STRUCTURE WITH COUNSEL
  Phase 4: PRM SELECTION                                 (platform + integration)
  Phase 5: MDF PROGRAM (if applicable)                    (accountability + ROI tracking)
  Phase 6: PERFORMANCE MEASUREMENT                       (partner-level + program-level)
```

## Instructions

### Phase 1 — Program design
Structure + tier benefits per selected partner mix.

### Phase 2 — Enablement design
Training + certification + tools + KB (coordinate with keel + grove).

### Phase 3 — Revenue-share structure (LOAD-BEARING)
Coordinate with operator + CFO + counsel for structure design (tax +
accounting + contract).

### Phase 4 — PRM selection
Platform decision (Impartner / Allbound / Salesforce PRM); integration
planning.

### Phase 5 — MDF program (if applicable)
Accountability framework + ROI tracking + audit process.

### Phase 6 — Performance measurement
Partner-level + program-level metrics; feedback loop to Phase 1 iteration.

## Output Format

- Program design memo
- Enablement plan
- Revenue-share structure brief for counsel
- PRM selection recommendation
- MDF program design (if applicable)
- Performance measurement framework

## Principles

1. **Never revenue-share structure without counsel** — LOAD-BEARING per
   failure mode 1.
2. **Enablement mandatory** — no partner signed without training + tools.
3. **Deal-registration rules explicit** — prevent channel conflict.
4. **PRM integration-first** — prevent sprawl.
5. **MDF accountability** — ROI tracking mandatory.
6. **No fabrication** — cited sources. Universal Principle 1.
7. **Aggregate-only at publication surface** — Universal Principle 2. Partner
   commercial terms stay in operator + counsel + PRM.
8. **Individual crisis HARD BOUNDARY** — Universal Principle 3 inherited.
9. **§0.6 flag.** Sources Tier B.

## Fallback

- **Revenue-share design pressure without counsel** — decline per Principle 1.
- **Channel conflict with internal sales** — coordinate with closer + operator.
- **PRM tool sprawl** — audit + consolidation plan.
- **MDF audit failure** — recover funds + program-policy update.
- **Individual crisis signal.** STOP. Route per Universal Principle 3.
