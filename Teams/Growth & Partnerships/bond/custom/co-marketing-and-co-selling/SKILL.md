# Co-Marketing and Co-Selling

## Introduction

Co-marketing + co-selling discipline for bond — Winning by Design + Rangan +
Impartner/Allbound + SiriusDecisions/Forrester + MarketingProfs/CMI.

Custom Route D per §8.2.

## Purpose

Prevents six failure modes:

1. **Co-marketing content without both-parties sign-off.** One-sided
   publication = brand-partner damage + potential defamation. LOAD-BEARING
   per Principle 1.
2. **Joint value proposition contradicts each side's positioning.** Confuses
   customers.
3. **Co-selling motion without clear roles.** Both parties chasing same
   customer without coordination = customer confusion.
4. **One-sided value capture.** Only one partner benefits from campaign =
   partnership erosion.
5. **Measurement asymmetry** — different attribution models each side =
   accounting disputes.
6. **Individual crisis DURING co-marketing crunch.** HARD BOUNDARY.

## Structure / Protocol

```
CO-MARKETING FORMATS

  - Joint webinar / event
  - Co-branded content (blog / ebook / whitepaper)
  - Joint case study (with customer)
  - Joint press release
  - Co-branded advertising campaign
  - Partner-integration content


CO-SELLING MOTIONS

  - Referral (partner introduces prospect)
  - Joint calls (both parties on prospect calls)
  - Territory / account co-coverage
  - Bundled offerings


JOINT VALUE PROPOSITION DESIGN

  - What does customer gain from combined offering
  - How does each partner contribute
  - Common messaging framework
  - Both sides' sign-off before external use


OPERATIONAL SEQUENCE:

  Phase 1: JOINT VALUE PROPOSITION DESIGN
  Phase 2: CO-MARKETING CAMPAIGN DESIGN
  Phase 3: CO-SELLING MOTION DESIGN
  Phase 4: LOAD-BEARING BOTH-PARTIES SIGN-OFF PROCESS
  Phase 5: MEASUREMENT (symmetric attribution)
```

## Instructions

### Phase 1 — Joint value proposition
Both partners' contributions + customer benefits + common messaging.

### Phase 2 — Co-marketing campaign design
Format selection + content briefs + timeline.

### Phase 3 — Co-selling motion design
Roles + territory / account coordination + handoff protocol.

### Phase 4 — Both-parties sign-off (LOAD-BEARING)
Every external co-branded artifact requires both-parties sign-off:
- Content review + approval
- Brand-guidelines compliance both sides
- Legal review both sides (coordinate with counsel)
- Explicit sign-off documented

### Phase 5 — Measurement
Symmetric attribution framework agreed both sides.

## Output Format

- Joint value proposition memo
- Co-marketing campaign brief
- Co-selling motion playbook
- Both-parties sign-off process + tracker
- Measurement framework (symmetric)

## Principles

1. **Never co-marketing content publication without both-parties sign-off** —
   LOAD-BEARING per failure mode 1.
2. **Joint value proposition consistent with each side's positioning.**
3. **Co-selling motion with clear roles** — no chaotic overlap.
4. **Balanced value capture** — both sides benefit.
5. **Symmetric attribution** — no accounting disputes.
6. **No fabrication** — cited sources. Universal Principle 1.
7. **Aggregate-only at publication surface** — Universal Principle 2. Partner-
   specific commercial data stays in operator + counsel + procurement.
8. **Individual crisis HARD BOUNDARY** — Universal Principle 3 inherited.
9. **§0.6 flag.** Sources Tier B.

## Fallback

- **Content publication pressure without both-parties sign-off** — decline
  per Principle 1. Coordinate sign-off or defer.
- **Positioning conflict** — coordinate joint-value-proposition revision.
- **Co-selling territory conflict** — coordinate with closer + operator.
- **Attribution dispute** — coordinate CFO + partner CFO for framework
  alignment.
- **Individual crisis signal.** STOP. Route per Universal Principle 3.
