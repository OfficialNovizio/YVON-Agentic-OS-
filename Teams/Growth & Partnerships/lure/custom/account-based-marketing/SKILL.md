# Account-Based Marketing

## Introduction

ABM discipline for lure — Terminus + Demandbase practitioner + Miller Heiman
stakeholder-mapping + Roberge revenue-machine + ITSMA/SiriusDecisions benchmarks.

Custom Route D per §8.2.

## Purpose

Prevents six failure modes:

1. **ABM personal-data compliance violation.** ABM inherently uses personal
   data (contact info + behavioral signals) — GDPR/CCPA/LGPD compliance
   mandatory. LOAD-BEARING per Principle 1.
2. **B2B outreach without counsel scoping.** Cold outreach in some jurisdictions
   (Germany UWG, EU ePrivacy) has strict requirements. LOAD-BEARING per
   Principle 2.
3. **Target-account selection without ICP.** Random accounts = wasted spend.
4. **Personalization without depth.** "Hi [FirstName]" not personalization.
5. **Sales-marketing misalignment.** ABM requires tight orchestration.
6. **Individual crisis DURING ABM-crunch.** HARD BOUNDARY.

## When to Use

Trigger on:

## Structure / Protocol

```
ABM TYPES (ITSMA framework)

  1-TO-1 ABM — deep personalization per named account (typically top 20-50)
  1-TO-FEW ABM — clustered accounts with common characteristics
  1-TO-MANY ABM — programmatic ABM at scale (100s-1000s of accounts)


TARGET ACCOUNT SELECTION

  ICP-based scoring:
    - Firmographic (industry / size / revenue / geography)
    - Technographic (tech stack fit)
    - Intent signals (research behavior, coordinate with data-provider
      per compliance)
    - Fit + intent = target-account list


PERSONALIZATION DEPTH (LOAD-BEARING data-compliance)

  Genuine personalization:
    - Account-specific research + insight
    - Custom content per account role
    - Executive-sponsor mapping (Miller Heiman)
    - Outreach cadence coordinated with sales

  Compliance: personal data collection + use per GDPR/CCPA/LGPD/PIPL
  frameworks (coordinate with canopy data-residency).


SALES-MARKETING ORCHESTRATION

  - Shared account list + tier + status
  - Coordinated outreach (marketing → sales handoff protocol)
  - Weekly account review (closer + lure joint)
  - Common metrics (account engagement / meeting-set / opportunity-created)


OPERATIONAL SEQUENCE:

  Phase 1: ABM TYPE SELECTION + ICP DEFINITION
  Phase 2: TARGET ACCOUNT SELECTION (LOAD-BEARING data-compliance)
  Phase 3: PERSONALIZATION DESIGN
  Phase 4: SALES-MARKETING ORCHESTRATION
  Phase 5: MEASUREMENT
```

## Instructions

### Phase 1 — ABM type selection + ICP definition
1-to-1 / 1-to-few / 1-to-many per resource + strategy fit.

### Phase 2 — Target account selection (LOAD-BEARING data-compliance)
ICP scoring + intent signals. **Data compliance per canopy** — no personal
data without lawful basis.

### Phase 3 — Personalization design
Account-specific research + custom content + role-based messaging.

### Phase 4 — Sales-marketing orchestration
Shared list + weekly reviews + common metrics with closer.

### Phase 5 — Measurement
Account engagement + meeting-set + opportunity-created + revenue-attributed.

## Output Format

- ABM strategy per segment
- Target account list with ICP + intent scoring
- Personalization playbook per account tier
- Sales-marketing orchestration design
- ABM performance dashboard

## Principles

1. **ABM personal-data compliance mandatory** — LOAD-BEARING per failure mode 1.
   Coordinate with canopy `data-residency-mapping`.
2. **B2B outreach counsel-scoped per jurisdiction** — LOAD-BEARING per failure
   mode 2. Germany UWG / EU ePrivacy specific requirements.
3. **ICP-based account selection** — no random accounts.
4. **Genuine personalization** — not "Hi [FirstName]".
5. **Sales-marketing orchestration** — no ABM without sales coordination.
6. **No fabrication** — cited sources. Universal Principle 1.
7. **Aggregate-only at publication surface** — Universal Principle 2. Individual
   account data stays in CRM + ABM tools.
8. **Individual crisis HARD BOUNDARY** — Universal Principle 3 inherited.
9. **§0.6 flag.** Sources Tier B.

## Fallback

- **Data-compliance uncertainty** — coordinate with canopy + counsel BEFORE
  ABM campaign launch.
- **Jurisdiction-specific outreach restriction** — coordinate with canopy +
  local counsel.
- **Sales-marketing misalignment** — escalate to quest + closer + operator.
- **Individual crisis signal.** STOP. Route per Universal Principle 3.
