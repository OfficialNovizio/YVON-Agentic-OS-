# Sales Methodology and Playbook

## Introduction

Sales methodology + playbook design for closer — MEDDIC/MEDDPICC + Dixon
Challenger Sale + Bosworth Solution Selling + Keenan Gap Selling + Winning
by Design.

**Scope distinction:** closer OWNS methodology design + playbook + coaching
framework. Sales reps EXECUTE methodology in customer conversations. Actual
sales delivery = operator + sales team.

Custom Route D per §8.2.

## Purpose

Prevents six failure modes:

1. **Fabricated commitments in sales conversations.** Sales rep promises
   product-capability or delivery-timeline that product cannot fulfill =
   trust damage + potential fraud claim. LOAD-BEARING per Principle 1.
2. **Methodology-agnostic selling.** Sales reps freelancing without shared
   methodology = inconsistent qualification + wasted cycles.
3. **Wrong-methodology for context.** Transactional MEDDIC applied to
   consultative-sale = under-discovery. Challenger applied to informed-buyer
   = over-education.
4. **Playbook stale.** Sales playbooks not updated as product/market evolve =
   drifting-from-current-best-practice.
5. **Coaching cadence absent.** Methodology adoption without coaching =
   inconsistent execution.
6. **Individual crisis DURING sales-crunch.** HARD BOUNDARY.

## Structure / Protocol

```
METHODOLOGY OPTIONS

  MEDDIC / MEDDPICC — complex enterprise deals
    - Metrics / Economic buyer / Decision criteria / Decision process /
      Identify pain / Champion (+ Paper process + Competition)
    - Best for: high-ACV enterprise; multi-stakeholder; long cycles

  CHALLENGER SALE (Dixon/Adamson) — insight-led selling
    - Teach / Tailor / Take control
    - Best for: informed buyers where insight differentiates

  SOLUTION SELLING (Bosworth) — pain-driven consultative
    - Diagnose pain → propose solution → close
    - Best for: solution-fit-obvious once pain diagnosed

  GAP SELLING (Keenan 2018) — current-state to future-state
    - Current state / Future state / Gap / Impact / Root cause
    - Best for: customer awareness of gap unclear at start

  SPIN SELLING (Rackham) — question-driven consultative
    - Situation / Problem / Implication / Need-payoff
    - Foundational for consultative-selling


PLAYBOOK COMPONENTS

  - Ideal Customer Profile (ICP)
  - Buyer persona (per role in decision)
  - Discovery questions per methodology
  - Objection handling library
  - Competitor battle-cards
  - Proof points + case studies (coordinate with retain customer-advocacy)
  - Pricing guidance (from quest pricing-and-packaging)
  - Contract templates (operator + counsel)
  - Handoff to CS (kickoff coordination)


OPERATIONAL SEQUENCE:

  Phase 1: METHODOLOGY SELECTION PER SEGMENT             (context-appropriate)
  Phase 2: PLAYBOOK DESIGN                                (ICP + persona + methodology-applied)
  Phase 3: COACHING CADENCE                               (methodology adoption + reinforcement)
  Phase 4: PLAYBOOK MAINTENANCE                           (periodic review + update)
```

## Instructions

### Phase 1 — Methodology selection per segment
Match methodology to context (deal size / cycle / buyer sophistication).

### Phase 2 — Playbook design
- ICP + buyer persona per segment
- Discovery questions applying selected methodology
- Objection handling + competitor battle-cards
- Proof points (coordinate with retain `customer-advocacy` for opted-in refs)
- Pricing guidance (from quest `pricing-and-packaging`)

### Phase 3 — Coaching cadence
- Ride-alongs / call reviews
- Weekly pipeline reviews with methodology-application check
- Coaching feedback loop (coordinate with merit for perf-mgmt)

### Phase 4 — Playbook maintenance
- Quarterly review — playbook effectiveness (win-rate / cycle-time / deal-size)
- Product update → playbook update
- Competitor movement → battle-card update

## Output Format

- Methodology recommendation per segment
- Playbook per segment (ICP / persona / discovery / objections / battle-cards / proof / pricing / handoff)
- Coaching cadence design
- Playbook maintenance schedule

## Principles

1. **Never fabricated commitments in sales conversations** — LOAD-BEARING per
   failure mode 1. Sales reps promise only product-capability + delivery-
   timeline product actually delivers. Escalate uncertainty to Product + operator.
2. **Methodology selected per context** — no single-methodology default.
3. **Playbook complete per segment** — all components documented.
4. **Coaching cadence mandatory** — methodology adoption requires reinforcement.
5. **Periodic playbook maintenance** — no stale playbooks.
6. **No fabrication** — cited sources. Universal Principle 1.
7. **Aggregate-only at publication surface** — Universal Principle 2. Individual
   rep performance data handled per HR + merit discipline.
8. **Individual crisis HARD BOUNDARY** — Universal Principle 3 inherited.
9. **§0.6 flag.** Sources Tier B.

## Fallback

- **Product-capability uncertainty** for prospect question — decline speculation
  per Principle 1. Escalate to Product + operator. Update playbook when
  capability confirmed.
- **New product / market — playbook not built** — coordinate with quest + Product
  for initial playbook draft; iterate with early sales cycles.
- **Individual crisis signal.** STOP. Route per Universal Principle 3.
