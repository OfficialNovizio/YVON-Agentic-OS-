# Time-To-First-Value Optimization

## Introduction

TTFV measurement + optimization discipline for kickoff. Bush 2019 PLG + Mehta
2016 first-value framing + Amplitude/Mixpanel activation-metrics + Sequoia
PLG playbook practitioner corpus.

**Scope distinction:** kickoff owns TTFV measurement + optimization. dana /
Product owns instrumentation; kickoff coordinates + interprets. Distinct from
`onboarding-journey-design` (kickoff sibling — journey structure) + `onboarding-
playbooks-per-segment` (playbook detail) + `kickoff-executive-alignment`
(enterprise Mutual Success Plan).

Custom Route D per §8.2.

## Purpose

Prevents six failure modes:

1. **Activation metrics fabricated.** Claiming TTFV improvement without cited
   data = Mehta discipline violation. LOAD-BEARING per Principle 1.
2. **First-value milestone unclear.** Without explicit "first-value" definition
   per segment, TTFV can't be measured consistently.
3. **Segment-agnostic TTFV.** Enterprise TTFV target ≠ SMB TTFV target ≠
   tech-touch TTFV target. Uniform target = wrong measurement per segment.
4. **Instrumentation gaps.** TTFV measurement requires product-analytics
   instrumentation; without dana/Product coordination, measurement is
   guesswork.
5. **Optimization without root-cause.** TTFV misses attributed to "product"
   or "customer" without root-cause = ineffective interventions.
6. **Individual crisis DURING TTFV crunch.** HARD BOUNDARY.

## Structure / Protocol

```
FIRST-VALUE MILESTONE DEFINITION (Mehta + Bush intersection)

  Definition varies per product + segment; typical elements:
    - Specific product action taken (e.g., "first campaign sent" for
      marketing platform; "first project shared" for collab tool)
    - Business-outcome tied (e.g., "first response received" not just
      "first message sent")
    - Time-bounded (e.g., within 7 days of onboarding start)
    - Cited definition — no vague "aha moment"


TTFV BENCHMARKS PER SEGMENT (Mehta 2016 + practitioner benchmarks)

  TECH-TOUCH        target minutes-to-hours (self-serve activation)
  HIGH-TOUCH        target days-to-weeks (CSM-led activation)
  ENTERPRISE        target weeks-to-months (custom implementation)

  Benchmarks refined per product + industry — cite source.


TTFV OPERATIONAL SEQUENCE:

  Phase 1: FIRST-VALUE MILESTONE DEFINITION            (per segment; cited)
  Phase 2: INSTRUMENTATION COORDINATION                (with dana/Product)
  Phase 3: BASELINE + BENCHMARK SETTING                 (current + target)
  Phase 4: GAP IDENTIFICATION + OPTIMIZATION            (root-cause analysis)
  Phase 5: HANDOFF TO ALLY HEALTH-SCORING BASELINE      (onboarding-stage close)
```

## Instructions

### Phase 1 — First-value milestone definition per segment

- Segment: tech-touch / high-touch / enterprise
- Specific product action tied to business outcome
- Time-bound criteria
- Cite definition source (Product + operator agreement)

### Phase 2 — Instrumentation coordination

Coordinate with dana / Product for:
- Event tracking for first-value action
- Funnel instrumentation (signup → activated milestones → first value)
- Segment tagging
- Cohort analysis capability

kickoff scopes what needs measuring; dana/Product instruments.

### Phase 3 — Baseline + benchmark setting

- Current TTFV per segment (cited from instrumentation data)
- Target TTFV per segment (industry benchmark + business-goal-driven)
- Gap size

### Phase 4 — Gap identification + optimization

Root-cause analysis for TTFV misses:
- Product friction (feature complexity / bugs / UX)
- Onboarding friction (unclear guidance / missing training / integration blockers)
- Customer-readiness gaps (stakeholder alignment / data readiness / adoption plan)

Per root cause: intervention owner + timeline + measurement.

### Phase 5 — Handoff to ally health-scoring baseline

At onboarding-stage close:
- Health-score baseline set using TTFV signals + other dimensions
- Coordinate with ally `customer-health-scoring` for handoff
- Lifecycle-value stage-1 (onboarding) marked complete
  (coordinate with ally `customer-lifecycle-value-mapping`)

## Output Format

- First-value milestone definition per segment (cited)
- Instrumentation coordination brief for dana/Product
- Baseline + benchmark report per segment
- Gap identification + optimization plan with root-cause
- Ally health-scoring baseline handoff brief

## Principles

1. **Activation metrics cited from instrumentation, not fabricated** —
   LOAD-BEARING per Purpose failure mode 1. Mehta discipline inherited.
2. **Explicit first-value milestone** per segment.
3. **Segment-appropriate TTFV target** — tech-touch / high-touch / enterprise.
4. **Instrumentation coordination mandatory** — dana / Product own execution.
5. **Root-cause analysis for TTFV misses** — not "product" or "customer"
   blame without evidence.
6. **No fabrication** — cited institutional + practitioner sources. Universal
   Principle 1.
7. **Aggregate-only at publication surface** — Universal Principle 2.
8. **Individual crisis HARD BOUNDARY** — Universal Principle 3 inherited.
9. **§0.6 flag.** Sources Tier B.

## Fallback

- **Instrumentation unavailable** for TTFV measurement. Coordinate with dana/
  Product for instrumentation-project; do NOT invent metrics from vibes.
  Interim: manual milestone tracking with explicit "manual — not
  instrumented" flag.
- **First-value milestone contested** (Product / CS / customer disagree).
  Escalate to operator + Product for definition alignment; document
  disagreement.
- **TTFV target unrealistic** for segment/product. Escalate to operator;
  target-adjustment vs product-improvement decision.
- **Individual crisis signal during TTFV conversation.** STOP. Route per
  Universal Principle 3 (inherited) to manager + HR Ops + EAP.
