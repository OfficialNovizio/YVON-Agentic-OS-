# Client Success — Department Workflow

> **ally** (Client Success Lead — Nick Mehta identity) sequences multi-agent
> Client Success work. This file documents standard sequencing patterns for
> events that span 2-4 agents in the department.

## Sequencing Principle

Per §2 (CLAUDE.md routing) + Prime Directive: multi-agent tasks route to the
department leader (**ally**) who sequences the others. ally never does
kickoff's or retain's or keel's work — ally sequences the sequence, checks
the seams, and enforces Mehta-flavored department-level disciplines at
coordination surfaces.

## Standard Sequencing Patterns

### Pattern A — Full Customer Lifecycle (all 4 agents)

**Trigger:** new customer onboarded through full lifecycle (contract signature
→ ongoing motion).

**ally sequences:**

1. **kickoff `onboarding-journey-design`** — sales-to-CS handoff (T-0) →
   tier-appropriate journey map → milestone map → coordination handoffs
2. **kickoff `kickoff-executive-alignment`** (enterprise tier) — MSP draft
   + stakeholder validation + BATNA + formalization
3. **kickoff `onboarding-playbooks-per-segment`** — playbook applied per tier
4. **kickoff `time-to-first-value-optimization`** — first-value milestone +
   instrumentation coordination + optimization
5. **kickoff → ally handoff at onboarding close** — health-score baseline
   (`customer-health-scoring`) + lifecycle-value stage-1 close
   (`customer-lifecycle-value-mapping`) + first QBR scheduled
   (`qbr-executive-review-framework`)
6. **retain siblings ongoing motion** — churn-risk monitoring; expansion
   motion identification (health-GREEN gated); renewal cadence T-90 to T-180
   before renewal date
7. **keel siblings support ongoing** — tiered support + SLA + support-signal
   feeds ally health-scoring + retain churn-risk
8. **ally `qbr-executive-review-framework`** — quarterly cadence with prior-
   QBR close-loop discipline

**Escalation:** operator + relevant counsel per Universal Principle 5 (LOAD-
BEARING) throughout. marcus / vista (Executive Office) for strategy-level
escalations.

### Pattern B — At-Risk Customer Save-Motion

**Trigger:** retain `churn-risk-prediction` identifies YELLOW/ORANGE/RED risk.

**ally sequences:**

1. **retain `churn-risk-prediction`** — signal inventory + tier scoring +
   save-motion design per tier
2. **YELLOW** — CSM-led save-motion via ally + retain coordination
3. **ORANGE** — executive-sponsor re-engagement + tailored save-plan
   coordinated with retain + operator
4. **RED** — operator + retain leadership + potentially exec-level save +
   contract-restructure discussion via retain `renewal-negotiation`
5. **Coordinate with keel** for support-signal input + support-quality
   assessment
6. **Coordinate with ally `qbr-executive-review-framework`** for risk
   discussion in QBR
7. **If reputation-adjacent** — escalate to **beacon** `crisis-comms` (Comms & PR)
8. **NO expansion push during save-motion** — LOAD-BEARING per retain
   `expansion-motions` Principle 1

### Pattern C — Renewal Cadence

**Trigger:** renewal window opens (T-90 to T-180 for enterprise; per tier
for others).

**ally sequences:**

1. **retain `renewal-negotiation` Phase 1** — renewal-window setup
2. **retain `renewal-negotiation` Phase 2 LOAD-BEARING** — value-realized-
   evidence assembly from:
   - ally `customer-health-scoring` (health history)
   - ally `customer-lifecycle-value-mapping` (milestone completion)
   - ally `qbr-executive-review-framework` (prior QBR commitments delivered)
   - keel `support-analytics` (support quality signals)
3. **retain `renewal-negotiation` Phase 3** — BATNA + relationship-context
   analysis
4. **retain `renewal-negotiation` Phase 4** — Fisher & Ury principled-
   negotiation with concessions-require-exchange discipline
5. **Coordinate with retain `expansion-motions`** for renewal-timing
   expansion (health-GREEN gated only)
6. **Coordinate with retain `customer-advocacy`** for multi-year renewal +
   advocacy program
7. **Material term changes** → operator + CFO + counsel (LOAD-BEARING per
   Universal Principle 5)
8. **Post-renewal commitment tracking** — feed back to ally
   `qbr-executive-review-framework` close-loop

### Pattern D — Expansion Opportunity

**Trigger:** ally `qbr-executive-review-framework` surfaces expansion
opportunity OR retain identifies opportunity signals.

**ally sequences:**

1. **retain `expansion-motions` Phase 1 LOAD-BEARING gate** — verify:
   - Health GREEN (from ally `customer-health-scoring`)
   - Value-realized per prior commitments (from ally
     `customer-lifecycle-value-mapping`)
   - No active escalations (from keel `support-analytics`)
   - Prior QBR commitments fulfilled (from ally
     `qbr-executive-review-framework`)
2. **If gate PASSES** → proceed to motion qualification + design +
   CS-to-sales handoff
3. **If gate FAILS** → DO NOT proceed with expansion. Coordinate with
   `churn-risk-prediction` if at-risk signals; with ally if value gaps
4. **Coordinate with future Growth & Partnerships** (when built) for sales
   execution
5. **Multi-team expansion** → new-team onboarding via kickoff

### Pattern E — Customer Reference Request (from herald / beacon / sales)

**Trigger:** herald press-kit request OR beacon investor-reference request
OR sales prospect-reference request.

**ally sequences:**

1. **retain `customer-advocacy` Phase 4** — process reference request
2. **LOAD-BEARING gate:** match to opted-in advocate roster + verify rate-
   limit + health-gate (no YELLOW/RED customers)
3. **Verify sign-off scope** per activity type (press ≠ investor ≠ sales
   reference; separate sign-off scopes required)
4. **Coordinate with requester** for advocate matching + facilitation
5. **Track advocate participation** + coordinate advocate-benefit follow-up
6. **Case-study data-verification** if new case study — no fabricated outcomes

### Pattern F — Support Escalation to Crisis

**Trigger:** keel support escalation reaches reputation-adjacent OR customer-
public-complaint level.

**ally sequences:**

1. **keel `sla-and-escalation-management`** — breach post-mortem + root-cause
2. **retain `churn-risk-prediction`** — customer-level churn-risk assessment
3. **retain `renewal-negotiation`** — renewal-risk assessment if renewal-
   adjacent
4. **Escalate to beacon `crisis-comms`** (Comms & PR) — if reputation-
   adjacent
5. **Coordinate with operator + retain leadership + potentially marcus / vista**

  vibes + customer-outcome-focused + no-vanity-metrics + community-oriented
  + expansion-when-earned + skeptical-of-CS-fluff

  across the department

  Principle 5
