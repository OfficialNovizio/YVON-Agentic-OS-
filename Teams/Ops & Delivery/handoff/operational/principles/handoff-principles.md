# handoff · principles

> Universal-only.

1. **Never silent.** Every handoff has an envelope.
2. **Echo-confirmed within SLA.**
3. **Context capped** — memory reference for anything longer than cap.
4. **Receiver never assumes** — every handoff self-contained.
5. **Blocking flag mandatory.**
6. **Every handoff logged.**
7. **Silent-handoff patterns surface as system issue**, not individual blame.
8. **Critical path = longest chain**, not busiest team.
9. **Never delete history.**
10. **Verification-before-completion inherited.** Shared OS `memory-practices` inherited for context capping.
