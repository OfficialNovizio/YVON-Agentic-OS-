Fix cost reporting for DeepSeek + stop task-conversion hijacking the thread

Reported from a live dashboard run of the offforum.com clone.

1. COST WAS BLANK ('price not in table (deepseek-flash)')
   token-cost.ts had zero DeepSeek entries, so the CAOS panel correctly refused
   to invent a number. Added real rates from DeepSeek's own docs
   (https://api-docs.deepseek.com/quick_start/pricing/, retrieved 2026-09-11).
   IMPORTANT: DeepSeek bills PEAK/OFF-PEAK (off-peak is exactly half; peak is
   01:00-04:00 and 06:00-10:00 UTC Mon-Fri). A flat table cannot express that, so
   the PEAK (upper-bound) rates are stored deliberately - a shown cost is never an
   understatement, and at off-peak the true bill is about half. Averaging the two
   would be a guess, which this file forbids. Legacy ids deepseek-v4-flash and
   deepseek-v4-flash-vision-exp are mapped too (retired upstream but still
   accepted, billed at Flash rates) so a stale id cannot blank cost reporting again.
