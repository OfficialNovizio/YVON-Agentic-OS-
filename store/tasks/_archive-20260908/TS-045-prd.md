# TS-045 · PRD — Run records in the task API

> Generated by spec · attached 2026-08-23 · fan-out 2 of 3 from the eng.integration session.

## 1 · Problem
A suite's verdict lives nowhere. `exit_gate.proof` accepts prose, which is why a self-assertion ("I verified it works") can pass — and why `gate` only proves a file was created, not that anything works. A failed run must be a datum, not a memory.

## 2 · Proposal
`/api/task-spec` returns run records: `run_ref`, per-criterion verdicts and evidence. A failed run is returned as failed, never omitted. Absent data returns `undefined`, never a default — a number you don't have must never render as a number you do. Backed by `dashboard/lib/db/runs.ts`.
